# Abstract
This project investigates the factors that influence student academic performance and evaluates whether machine learning models can reliably predict final outcomes using real-world educational data. Two publicly available datasets were analyzed: one from the UCI Machine Learning Repository and one from Mendeley Data. Statistical analyses using two-sample Z-tests showed that gender, extracurricular participation, and study time were significantly associated with performance, while income, absences, and academic support variables did not demonstrate meaningful differences between groups. Three supervised learning models—Logistic Regression, Decision Tree, and Random Forest—were trained to predict student pass/fail outcomes, with the Random Forest model achieving the highest accuracy. The results demonstrate that early-term grades serve as strong predictors of final academic performance and highlight the value of data-driven approaches for identifying at-risk students and informing targeted educational interventions.

Keywords—Student performance, machine learning, classification models, Z-test analysis, academic achievement, Random Forest, Logistic Regression, Decision Tree, predictive modeling, educational analytics
